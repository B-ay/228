# 寝室 228 · 静态网页导航

HTML/CSS/JavaScript 静态网页集合，首页提供两个成员页面的导航。适合作为早期网页实践归档。

## 目录入口

- `index.html`：寝室导航页。
- `zb426/web/`：旅行主题子页面及对应资源。
- `zsl424/Web/`：成员个人展示子页面。
- `images/`：首页素材。

## 本地预览

在仓库根目录运行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

打开 http://127.0.0.1:8000/ 。
